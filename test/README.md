# Social Blend

A modern social media platform that combines elements from LinkedIn, Reddit, and Twitter.

## Features

- Modern, responsive design
- Platform-specific styling for posts
- Interactive post components with likes, comments, and shares
- Trending topics sidebar
- Search functionality
- Create post button

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

```bash
npm start
```

The application will be available at [http://localhost:3000](http://localhost:3000).

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- React Icons

## Project Structure

- `src/App.tsx` - Main application component
- `src/components/Post.tsx` - Post component for displaying individual posts
- `src/index.tsx` - Application entry point
- `src/index.css` - Global styles and Tailwind imports
